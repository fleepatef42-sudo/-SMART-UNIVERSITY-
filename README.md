# Smart University

Responsive university management dashboard concept for organizing academic operations from one admin interface.

## Live Demo

- Live: https://fleepatef42-sudo.github.io/-SMART-UNIVERSITY-/
- Source: https://github.com/fleepatef42-sudo/-SMART-UNIVERSITY-

## Features

- Dashboard views for students, courses, faculty, admissions, exams, library records, and financial invoices.
- Modal forms for adding new records.
- Global search interaction.
- Notification UI and profile dropdown.
- Data tables, stat cards, and compact chart-style visuals.
- Arabic interface with responsive layout behavior.

## Tech Stack

- HTML5
- CSS3
- JavaScript
- Font Awesome

## Project Note

This is a client-side admin dashboard demo. It focuses on UI structure, form flows, and dashboard interactions.
